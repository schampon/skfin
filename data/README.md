# External Datasets

This directory contains cached copies of third-party datasets used in the skfin2 teaching notebooks. These files are redistributed for educational purposes only.

---

## Loughran-McDonald Master Dictionary

| | |
|---|---|
| **File** | `Loughran-McDonald_MasterDictionary_1993-2021.csv` |
| **Size** | ~8.5 MB |
| **Authors** | Tim Loughran and Bill McDonald |
| **Source** | [Software Repository for Accounting and Finance (SRAF)](https://sraf.nd.edu/loughran-mcdonald-master-dictionary/) |
| **Description** | Word-level sentiment dictionary for financial text. Each row is a word with flags for positive, negative, uncertainty, litigious, and other tone categories. Widely used for sentiment analysis of SEC filings and earnings calls. |
| **Citation** | Loughran, T. and McDonald, B. (2011). "When Is a Liability Not a Liability? Textual Analysis, Dictionaries, and 10-Ks." *Journal of Finance*, 66(1), 35-65. |

## Loughran-McDonald 10-X Summaries

| | |
|---|---|
| **File** | `Loughran-McDonald_10X_Summaries_1993-2021.csv` |
| **Size** | ~167 MB |
| **Authors** | Tim Loughran and Bill McDonald |
| **Source** | [SRAF SEC EDGAR Data](https://sraf.nd.edu/sec-edgar-data/lm_10x_summaries/) |
| **Description** | Document-level summary statistics for 10-K and 10-Q filings from SEC EDGAR (1993-2021). Includes file size, word count, sentiment scores, and filing metadata. |
| **Citation** | Loughran, T. and McDonald, B. (2011). "When Is a Liability Not a Liability? Textual Analysis, Dictionaries, and 10-Ks." *Journal of Finance*, 66(1), 35-65. |

## Goyal-Welch Predictive Variables

| | |
|---|---|
| **File** | `Data2024.xlsx` |
| **Size** | ~1.1 MB |
| **Authors** | Amit Goyal and Ivo Welch |
| **Source** | [Amit Goyal's Data Library](https://sites.google.com/view/agoyal145/data-library) |
| **Description** | Monthly and annual U.S. equity market predictors (1871-2024): dividend-price ratio, earnings-price ratio, book-to-market, Treasury bill rate, long-term yield, default spread, inflation, and other macro variables used in return predictability research. |
| **Citation** | Goyal, A. and Welch, I. (2008). "A Comprehensive Look at The Empirical Performance of Equity Premium Prediction." *Review of Financial Studies*, 21(4), 1455-1508. |
